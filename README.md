# Sali-Localo — هوش مصنوعی آفلاین روی گوشی

![Android 7.0+](https://img.shields.io/badge/Android-7.0%2B-3ddc84?logo=android&logoColor=white)
![100% offline](https://img.shields.io/badge/100%25-offline-e91e63)
![arm64-v8a](https://img.shields.io/badge/ABI-arm64--v8a-8a2be2)

**Sali-Localo** یعنی هوش مصنوعی، بدون اینترنت و بدون فرستادن چیزی به جایی. یک برنامهٔ اندرویدی سبک که مدل زبانی را **روی خود گوشی** اجرا می‌کند: فایل مدل (`GGUF`) را از حافظهٔ گوشی انتخاب می‌کنی و همان‌جا، حتی در حالت پرواز، جواب می‌گیری. نه سروری در کار است، نه اشتراک ماهانه، نه حسابی که بسازی.

<br>

|---|---|

| ⚡ **روی گوشی‌های معمولی** | بهینه برای Redmi Note 14 Pro (Helio G100-Ultra): بارگذاری `mmap` بدون کپی وزن‌ها، ۴ نخ تولید، پایش واقعی رم و دما. |
| 💬 **چت، سند و صدا** | گفت‌وگوی چندنوبتی با پخش زندهٔ توکن، الحاق فایل و جست‌وجوی محلی در اسناد، رونویسی صوت آفلاین با Whisper. |
| 🎛️ **کنترل کامل** | دما، top-p/k، طول پاسخ، پنجرهٔ context و تعداد نخ‌ها — با ذخیرهٔ دائمی و محدودهٔ ایمن سخت‌افزاری. |
| 🧠 **شفاف، بدون ادعا** | هر قابلیت یا واقعاً کار می‌کند یا صریحاً «کار نمی‌کند» اعلام می‌شود؛ موتور جعلی در این پروژه جایی ندارد. |

**A tiny Android app that runs GGUF language models on your phone — 100% offline, no account, no cloud, no telemetry.**

---

## 📖 توضیحات جامع

یک اپلیکیشن کاملاً آفلاین اندروید برای اجرای مدل‌های هوش مصنوعی **روی خود گوشی** — بدون اینترنت، بدون سرویس ابری، بدون تله‌متری.

## ✨ چه چیزی واقعاً کار می‌کند (وضعیت صادقانه)

| قابلیت | وضعیت |
|---|---|
| گفت‌وگو با مدل‌های زبانی GGUF (llama.cpp) | ✅ **استنتاج واقعی** — بارگذاری مدل از حافظهٔ گوشی، تولید توکن‌به‌توکن، گفت‌وگوی چندنوبتی، لغو تولید |
| کنترل پارامترهای تولید (دما، top-p/k، طول پاسخ، تکرار، context، نخ‌ها) | ✅ با ذخیرهٔ دائمی و محدودهٔ امن سخت‌افزاری |
| ایمنی سخت‌افزار (فشار RAM سیستم، حرارت رسمی Android) | ✅ توقف خودکار هنگام فشار واقعی حافظه/حرارت |
| وارد کردن فایل‌های ZIP/سند/تصویر و الحاق به پرامپت | ✅ محتوای استخراج‌شده واقعاً به مدل داده می‌شود |
| بازیابی محلی RAG (بردار واژگانی) + تزریق نتایج به پرامپت | ✅ قطعات مرتبط واقعاً به مدل داده می‌شوند (امتیازدهی lexical) |
| مدل‌های استدلالی (`<think>`) | ✅ جریان تفکر زنده از پاسخ تفکیک و ذخیره می‌شود |
| تولید تصویر پیکسلی | ❌ موتور diffusion بسته‌بندی نشده — UI صادقانه اعلام می‌کند |
| تبدیل صوت به متن | ✅ **whisper.cpp واقعی** — بارگذاری مدل Whisper (GGUF)، رمزگشایی صوت با MediaCodec، رونویسی آفلاین |
| خواندن متن با صدا (TTS) | ✅ از TTS سیستمی Android (آفلاین) |

> ادعاها صادقانه‌اند: موتورهای جعلی در این پروژه جایی ندارند؛ هر چیزی که اجرا نشود، به‌وضوح «اجرا نمی‌شود» برچسب می‌خورد.

## 📱 دستگاه هدف

بهینه‌سازی‌شده برای **Xiaomi Redmi Note 14 Pro 4G** (Helio G100-Ultra، ۲×A76 + ۶×A55، Mali-G57 MC2، UFS 2.2):

- پروفایل Turbo: **۴ نخ تولید** و **۶ نخ پردازش پرامپت** (برای کاهش زمان پردازش پرامپت‌های طولانی)
- پیش‌فرض‌های محافظه‌کارانه: context ۲۰۴۸، حداکثر ۵۱۲ توکن پاسخ
- فقط ABI `arm64-v8a` (APK سبک‌تر)
- مدل‌ها با mmap بارگذاری می‌شوند؛ وزن‌ها هرگز کپی نمی‌شوند
- پایش فشار واقعی حافظهٔ سیستم (نه PSS فرایند) — چون صفحات mmap قابل بازپس‌گیری‌اند
- در HyperOS برای اجرای طولانی، Autostart را روشن و صرفه‌جویی باتری برنامه را روی «بدون محدودیت» بگذارید

## 🚀 دریافت APK

1. به صفحهٔ [Actions](../../actions/workflows/build-android-apk.yml) بروید (هر پوش روی `main` به‌صورت خودکار APK می‌سازد).
2. آخرین اجرای موفق (`Android APK`) را باز کنید.
3. در بخش **Artifacts** فایل `Sali-Localo-release-apk` را دانلود و `app-release.apk` را نصب کنید.

هر نسخه با کلید انتشار پایدار امضا می‌شود؛ نصب‌های بعدی **در‌جا (in-place)** ارتقا می‌یابند.

## 🧠 استفاده از مدل‌های واقعی

1. یک فایل **GGUF** مدل زبانی (مثلاً `Qwen2.5-3B-Instruct Q4_K_M` یا مدل کوچک‌تر) را از منبع معتبر دانلود و در حافظهٔ گوشی قرار دهید.
2. در برنامه، از بخش **مدل‌ها** (یا پیوست فایل در گفت‌وگو) فایل `.gguf` را انتخاب کنید.
3. برنامه فایل را اعتبارسنجی (magic و فرادادهٔ GGUF)، پیش‌آزمون حافظه انجام می‌دهد و سپس **واقعاً بارگذاری می‌کند**.
4. گفت‌وگو کنید — توکن‌ها به‌صورت زنده پخش می‌شوند و هر لحظه قابل توقف‌اند.

**راهنمای اندازه:** مدل‌های ۱–۳ میلیارد پارامتر با کوانتیزاسیون Q4 برای این گوشی ایده‌آل‌اند. مدل‌های ۷B–۸B با کوانتیزاسیون Q3 روی رم ۸ گیگابایتی نیز با **mmap** بارگذاری می‌شوند، اما سرعت پایین و فشار حافظه را باید انتظار داشت؛ برای تجربهٔ روان‌تر ۳B–۴B مناسب‌تر است. قبل از بارگذاری مدل بزرگ، برنامه‌های دیگر را ببندید.

> فرمت‌های `safetensors`/`ckpt`/Flux/SDXL مدل‌های diffusion هستند و با llama.cpp اجرا نمی‌شوند؛ این نسخه فقط GGUF متنی و Whisper را می‌شناسد و فایل‌های ناسازگار را با پیام روشن رد می‌کند.

## 🎙️ تبدیل صوت به متن (Whisper)

1. یک مدل **Whisper GGUF** (مثلاً `whisper-base` یا `whisper-small`) را دانلود کنید.
2. در بخش «صوت و گفتار»، دکمهٔ «وارد کردن مدل Whisper (GGUF)» را بزنید.
3. فایل صوتی (WAV/MP3/M4A) را انتخاب کنید — رمزگشایی و رونویسی کاملاً روی گوشی انجام می‌شود.

## ⚡ بهینه‌سازی‌های کارایی (Redmi Note 14 Pro / Helio G100-Ultra)

- **بازاستفاده از KV-cache در گفت‌وگوی چندنوبتی:** فقط توکن‌های جدید هر نوبت پردازش می‌شوند؛ پاسخ‌های بعدی چند برابر سریع‌تر شروع می‌شوند (تطابق دقیق توکن‌ها؛ در صورت هر عدم تطابق، ارزیابی کامل انجام می‌شود).
- **پیش‌پردازش نوبتی (batch) تا ۱۰۲۴ توکن** — جمع‌بندی گفت‌وگوهای بلند سریع‌تر.
- **R8 + حذف منابع بی‌استفاده:** APK سبک‌تر و اجرای سریع‌تر برنامه (با قواعد ایمن JNI).
- **بارگذاری مدل با mmap** بدون کپی وزن‌ها + **نمایش زندهٔ درصد پیشرفت** هنگام بارگذاری.
- **پردازش صوت با آرایه‌های primitive** (بدون boxing) و سقف ۱۰ دقیقه برای ایمنی حافظه.
- **بچ‌شدن توکن‌های UI در پنجرهٔ ۳۰ میلی‌ثانیه** — روان در نمایش ۱۲۰ هرتز بدون فشار به CPU.
- **تفکیک نخ تولید و پردازش پرامپت:** ۴ نخ برای تولید توکن و ۶ نخ برای پردازش پرامپت روی Helio G100-Ultra؛ هدف، کوتاه‌تر شدن زمان شروع پاسخ‌های طولانی است بدون اینکه تولید توکن گرمای بیشتری بسازد.
- **پیش‌فرض‌های محافظه‌کارانه:** context ۲۰۴۸، توقف خودکار زیر فشار حافظه/حرارت.

## 🛠️ ساخت از سورس

```bash
# 1) دریافت llama.cpp + whisper.cpp (پین‌شده — همان نسخه‌های CI)
mkdir -p app/src/main/cpp/llama.cpp app/src/main/cpp/whisper.cpp
curl -sSL https://codeload.github.com/ggml-org/llama.cpp/tar.gz/refs/tags/v0.6.0 \
  | tar xz --strip-components=1 -C app/src/main/cpp/llama.cpp
curl -sSL https://codeload.github.com/ggml-org/whisper.cpp/tar.gz/refs/tags/v1.9.5 \
  | tar xz --strip-components=1 -C app/src/main/cpp/whisper.cpp

# 2) ساخت APK (نیازمند JDK 21، Android SDK 36، NDK 27.2، CMake 3.22.1)
./gradlew assembleRelease
# خروجی محلی بدون KEYSTORE_PATH/STORE_PASSWORD/KEY_PASSWORD امضا نمی‌شود؛
# CI با کیستور مخفی یا کیستور تولیدشده و کش‌شده APK را امضا می‌کند.
```

پوشه‌های `app/src/main/cpp/llama.cpp/` و `app/src/main/cpp/whisper.cpp/` در `.gitignore` هستند؛ سورس در زمان ساخت واکشی می‌شود.

## 🧪 تست‌ها

- تست‌های JVM (Robolectric/JUnit) روی پارامترهای تولید، چرخهٔ بارگذاری، پخش توکن، لغو و نگاشت خطا — با backend جعلی در seam قرارداد.
- صداقت تست: تست‌های JVM **عددسازی native را ادعا نمی‌کنند**؛ کتابخانهٔ بومی فقط روی دستگاه arm64 اجرا می‌شود.

## 🔒 حریم خصوصی

- بدون مجوز `INTERNET` در manifest — برنامه اساساً قادر به اتصال شبکه نیست.
- بدون Firebase، analytics یا SDK تبلیغاتی.
- همهٔ داده‌ها (گفت‌وگوها، فایل‌ها، مدل‌ها) در حافظهٔ داخلی گوشی می‌مانند.
